Trilha JavaScript

Guia Definitivo: Do JavaScript ao TypeScript (Sem Complicação)

Fundamentos para entender a linguagem antes de avançar para TypeScript, backend e aplicações reais.

Regra de ouro: TypeScript é uma armadura colocada sobre JavaScript. O motor que executa o código continua sendo JavaScript puro.

Por que começar pelo JavaScript?

Se você dominar a lógica básica do JavaScript, programar em TypeScript será muito mais natural. Variáveis, objetos, arrays, classes e assincronismo continuam seguindo as regras do JavaScript.

1. Variáveis modernas: const versus let

Esqueça o antigo var. Use const para referências que não serão reatribuídas e let quando o valor precisar mudar.

const nome = "Nicolas"; // A referência não muda.
let tentativas = 0; // O contador pode mudar.
tentativas = tentativas + 1; // Atualiza o valor.

2. Memória: primitivo versus referência

Números, textos e booleanos são copiados por valor. Cada variável recebe seu próprio valor.

let saldoOriginal = 100;
let copiaSaldo = saldoOriginal; // Cria uma cópia isolada.
copiaSaldo = 200; // Altera somente a cópia.
console.log(saldoOriginal); // Continua sendo 100.

Objetos e arrays guardam uma referência para a mesma estrutura. A atribuição não cria uma cópia profunda.

const usuario1 = { nome: "Nicolas" };
const usuario2 = usuario1; // Apontam para o mesmo objeto.

usuario2.nome = "Lucas"; // Altera o objeto compartilhado.
console.log(usuario1.nome); // Também imprime "Lucas".
Atenção: const impede trocar a caixa inteira, mas ainda permite alterar propriedades internas.

3. Comparações: sempre use ===

== tenta converter tipos antes de comparar. === compara tipo e valor sem coerção implícita.

console.log(0 == false); // true: houve coerção.
console.log(0 === false); // false: tipos diferentes.
console.log(10 === 10); // true: tipo e valor iguais.

4. Objetos e parâmetros limpos

Em vez de criar funções com muitos argumentos soltos, agrupe os dados em um objeto. Isso facilita a leitura e a evolução da API.

function criarConta(dados) {
  console.log(`Criando conta para ${dados.nome}, Saldo: ${dados.saldo}`);
}

const novaConta = { nome: "Nicolas", idade: 20, saldo: 500 };
criarConta(novaConta);

Desestruturação extrai diretamente os campos necessários:

const { nome, saldo } = novaConta;
console.log(nome); // "Nicolas"
console.log(saldo); // 500

5. Os quatro métodos de listas mais usados

map transforma e devolve uma nova lista; filter seleciona itens; find devolve o primeiro item encontrado; reduce acumula tudo em um único resultado.

const tarefas = [
  { id: 1, titulo: "Estudar JS", feita: true },
  { id: 2, titulo: "Aprender TS", feita: false }
];

const encontrada = tarefas.find((tarefa) => tarefa.id === 1);
const pendentes = tarefas.filter((tarefa) => !tarefa.feita);
const titulos = tarefas.map((tarefa) => tarefa.titulo);
const total = tarefas.reduce((quantidade) => quantidade + 1, 0);

6. O básico de classes

Uma classe é a planta de uma fábrica. O objeto criado com new é a instância real pronta para uso.

class Carro {
  constructor(marca, modelo) {
    this.marca = marca;
    this.modelo = modelo;
  }

  buzinar() {
    console.log(`${this.modelo} fez: Bi-bi!`);
  }
}

const meuCarro = new Carro("Peugeot", "408");
meuCarro.buzinar();

7. Assincronismo: async, await e try/catch

Operações demoradas, como APIs e banco de dados, aguardam respostas sem travar o restante da aplicação.

async function carregarDados() {
  try {
    const resposta = await fetch("https://api.exemplo.com/usuarios");
    const dados = await resposta.json();
    console.log("Dados carregados com sucesso:", dados);
  } catch (erro) {
    console.error("Houve uma falha:", erro.message);
  }
}

carregarDados();
Resumo: async cria uma função assíncrona, await aguarda uma Promise e catch trata a falha.
