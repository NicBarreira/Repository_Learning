The following character escapes are recognized in regular expressions:

Represents the control character with value equal to the letter's character value modulo 32. For example,
\cJ

\n

J

\cJ
and
\cj

In
Unicode-unaware mode
, escape sequences that are not one of the above become

: they represent the character that follows the backslash. For example,
\a

In Unicode-unaware mode,

{

In Unicode-unaware mode, escape sequences within

\cX

X
is a number or
_

ASCII
letters:
\c0

\cP
when taken modulo 32. In addition, if the form
\cX

X

js
/[\c0]/.test("\x10"); // true
/[\c_]/.test("\x1f"); // true
/[\c*]/.test("\\"); // true
/\c/.test("\\c"); // true
/\c0/.test("\\c0"); // true (the \c0 syntax is only supported in character classes)
Examples
Using character escapes
Character escapes are useful when you want to match a character that is not easily represented in its literal form. For example, you cannot use a line break literally in a regex literal, so you must use a character escape:
js
const pattern = /a\nb/;
const string = `a
b`;
console.log(pattern.test(string)); // true
