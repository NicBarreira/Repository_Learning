The
GeneratorFunction
object provides methods for
generator functions
. In JavaScript, every generator function is actually a
GeneratorFunction
object.
Note that
GeneratorFunction
is
not
a global object. It can be obtained with the following code:
js
const GeneratorFunction = function* () {}.constructor;
GeneratorFunction
is a subclass of
Function
.

Try it
const GeneratorFunction = function* () {}.constructor;

const foo = new GeneratorFunction(`
  yield 'a';
  yield 'b';
  yield 'c';
`);

let str = "";
for (const val of foo()) {
  str += val;
}

console.log(str);
// Expected output: "abc"

All generator functions share the same
