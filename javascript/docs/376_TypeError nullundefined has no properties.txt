TypeError: null/undefined has no properties
The JavaScript exception "null (or undefined) has no properties" occurs when you
attempt to access properties of
null
and
undefined
. They
don't have any.

What went wrong?
Both
null
and
undefined
have no properties you could access. Therefore, you cannot use
property accessors
on them, or
destructure
them.
Examples
null and undefined have no properties
js
null.foo;
// TypeError: null has no properties

undefined.bar;
// TypeError: undefined has no properties
