Nível Intermediário: APIs REST e Regras de Negócio

Servidores funcionais, rotas, middlewares, integrações externas e configurações seguras.

O que muda no nível intermediário?

Depois de dominar scripts e módulos, o foco passa a ser construir APIs que recebem requisições, validam dados, executam regras de negócio e respondem com status HTTP apropriados.

1. Servidores HTTP com Express

O módulo node:http é suficiente, mas o Express reduz código repetitivo e organiza rotas e middlewares.

import express from "express";

const app = express();
app.use(express.json());

app.get("/usuarios", (req, res) => {
  res.status(200).json([{ id: 1, nome: "Nicolas" }]);
});

app.post("/usuarios", (req, res) => {
  res.status(201).json({ mensagem: "Usuário criado", dados: req.body });
});

app.listen(3000, () => console.log("API em http://localhost:3000"));

Use 200 para sucesso de leitura, 201 para criação, 400 para entrada inválida, 404 para recurso inexistente e 500 para falhas inesperadas.

2. Parâmetros e middlewares

req.params lê valores da rota, req.query lê filtros após ? e req.body contém o JSON enviado pelo cliente.

app.get("/usuarios/:id", (req, res) => {
  const id = Number(req.params.id);
  const termo = req.query.termo ?? "";

  res.json({ id, termo });
});

Middlewares interceptam a requisição antes da rota final. express.json(), por exemplo, converte o corpo bruto em um objeto JavaScript.

3. Variáveis de ambiente e segurança

Portas, senhas e chaves secretas não devem ficar no código. Use .env, mantenha-o no .gitignore e carregue-o no Node moderno com --env-file.

# .env
PORT=3000

# terminal
node --env-file=.env src/server.js

// server.js
const porta = Number(process.env.PORT ?? 3000);
console.log(`API usando a porta ${porta}`);

4. APIs externas e persistência básica

Use fetch para parceiros externos e node:fs/promises para arquivos JSON locais. Toda operação externa deve tratar falhas.

import { readFile, writeFile } from "node:fs/promises";

async function carregarClima() {
  try {
    const resposta = await fetch("https://api.exemplo.com/clima");
    if (!resposta.ok) throw new Error(`HTTP ${resposta.status}`);
    return await resposta.json();
  } catch (erro) {
    console.error("Falha na API externa:", erro.message);
    throw erro;
  }
}

const contas = JSON.parse(await readFile("./contas.json", "utf8"));
await writeFile("./backup-contas.json", JSON.stringify(contas, null, 2));
