Trilha Node.js

Guia Definitivo: Node.js para Back-End — Iniciante

O ambiente, o ecossistema de pacotes e os primeiros scripts executados fora do navegador.

Regra de ouro: Node.js não é uma linguagem nem um framework. É um runtime que usa o motor V8 para executar JavaScript no computador ou servidor.

1. O que é o Node.js afinal?

O navegador oferece DOM e APIs de interface. O Node.js executa JavaScript fora do navegador e acrescenta APIs para arquivos, processos, rede, terminal e streams.

console.log(typeof document); // undefined no Node.js
console.log(process.platform); // sistema operacional atual
console.log(process.version); // versão do runtime

2. NPM e o package.json

Todo projeto pode começar com npm init -y. O arquivo package.json funciona como o documento do projeto.

  • scripts: atalhos como node --watch server.js.
  • dependencies: bibliotecas necessárias em produção.
  • node_modules: dependências instaladas; nunca deve ir para o Git.
  • package-lock.json: versões exatas para instalações reproduzíveis.
npm init -y
npm install express
npm run dev

3. Sistema de módulos: CommonJS e ESM

CommonJS é o formato tradicional do Node.js. ESM é o padrão moderno, baseado em import e export. Para ativá-lo, use "type": "module" no package.json.

// matematica.js
export function somar(a, b) {
  return a + b;
}

// index.js
import { somar } from "./matematica.js";
console.log(somar(2, 3));

4. Execução e entrada pelo terminal

Execute arquivos com node nomeDoArquivo.js. Para coletar respostas do teclado de forma assíncrona, use node:readline/promises.

import { createInterface } from "node:readline/promises";
import { stdin as entrada, stdout as saida } from "node:process";

const terminal = createInterface({ input: entrada, output: saida });
const nome = await terminal.question("Qual é o seu nome? ");
console.log(`Olá, ${nome}!`);
terminal.close();
Prática: use node --watch arquivo.js durante o estudo para reiniciar o script automaticamente.
