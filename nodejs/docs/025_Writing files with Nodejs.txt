if it does already exist.
You can modify the default by specifying a flag:

The flags you'll likely use are
Flag
Description
File gets created if it doesn't exist

This flag opens the file for
reading
and
writing
❌

This flag opens the file for

and
writing

beginning

✅
a
This flag opens the file for
writing

✅

This flag opens the file for

and
